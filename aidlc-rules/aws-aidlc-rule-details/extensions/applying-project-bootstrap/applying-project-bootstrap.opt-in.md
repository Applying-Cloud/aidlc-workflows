## Applying Project Bootstrap

¿Deseas que configure automáticamente la estructura de repositorios,
workspace y steering files para este proyecto?

Esto incluye:
- Crear repositorios en GitHub según la estrategia definida
- Configurar el workspace del IDE (Kiro)
- Seleccionar y distribuir steering files desde el catálogo central de Applying
- Configurar skills relevantes por componente
- Generar commit inicial con la estructura lista para construction

Requisitos: GitHub CLI (`gh`) instalado y autenticado.
